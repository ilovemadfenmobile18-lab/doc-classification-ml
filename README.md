## 👥 Команда и распределение ролей
* **Data Engineer (Инженер данных):** сбор и паспортизация датасета (`dataset.csv`), разведочный анализ данных (EDA), очистка регулярными выражениями, морфологическая лемматизация (`pymorphy3`), стратифицированное разбиение выборки, построение матрицы признаков TF-IDF (униграммы + биграммы).
* **ML & Validation Engineer (Инженер машинного обучения):** подбор гиперпараметров (`GridSearchCV`), обучение пула моделей (`MultinomialNB`, `LogisticRegression`, `LinearSVC`, `RandomForestClassifier`), сравнительный анализ с Baseline, оценка на тестовом множестве, построение Confusion Matrix, Error Analysis (10 краевых случаев) и профилирование производительности инференса.

## 🛠 Архитектура и стек технологий
* **Язык:** Python 3.10+
* **Предобработка:** `pymorphy3` (морфологический анализ, нормализация словоформ), регулярные выражения (`re`)
* **Векторизация:** `TfidfVectorizer(ngram_range=(1, 2), max_features=3000, sublinear_tf=True)`
* **Моделирование:** `scikit-learn` (`LinearSVC`, `CalibratedClassifierCV`)
* **Калибровка и маршрутизация:** доверительный порог уверенности `Threshold = 0.60` (при падении ниже порога запрос перенаправляется на ручную верификацию оператору)
* **Сериализация:** `joblib` (`model_pipeline.joblib`)
