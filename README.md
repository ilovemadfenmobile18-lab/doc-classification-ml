# Автоматическая классификация входящих корпоративных документов

Курсовая работа по дисциплине «Прикладные интеллектуальные системы» (БГУИР, ИИТ, 2026).

## 1. Описание проекта
Разработка прототипа интеллектуальной системы классификации входящей корпоративной документации по типу документа и целевому отделу с применением классического машинного обучения (TF-IDF + линейные классификаторы).

## 2. Структура проекта
- `data/` — датасет и паспорта данных (`dataset.csv`).
- `notebooks/` — эксперименты, разведочный анализ данных (EDA) и обучение моделей.
- `docs/` — материалы пояснительной записки.

## 3. Архитектура и стек технологий
- Язык: Python
- Предобработка: pymorphy3, NLTK
- Извлечение признаков: TF-IDF (word & char n-grams)
- Моделирование: Scikit-Learn (LogisticRegression, LinearSVC, MultinomialNB)
- Метрики оценки: Macro-F1 (целевой порог >= 0.85), Accuracy
