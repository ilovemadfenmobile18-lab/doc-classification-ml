Курсовая работа по дисциплине «Прикладные интеллектуальные системы» (БГУИР, ИИТ, 2026)[cite: 6, 8].  
Специальность: 6-05-0612-01 «Программная инженерия»[cite: 6, 8].

## Распределение ролей в исследовательской группе
* **Data Engineer (Инженер данных):** сбор и паспортизация набора данных (`dataset.csv`), первичный разведочный анализ данных (EDA), фильтрация шума регулярными выражениями, морфологическая лемматизация (`pymorphy3`), стратифицированное разбиение выборки, построение матрицы признаков TF-IDF на униграммах и биграммах[cite: 9, 14, 21].
* **ML & Validation Engineer (Инженер машинного обучения):** подбор гиперпараметров методом решетчатого поиска (`GridSearchCV`), обучение пула классификаторов (`MultinomialNB`, `LogisticRegression`, `LinearSVC`, `RandomForestClassifier`), сопоставление с эвристическим Baseline, валидация на отложенной выборке, построение матрицы ошибок, качественный анализ 10 граничных случаев (Error Analysis) и профилирование задержки инференса[cite: 9, 14, 15, 16].

## Архитектура программного конвейера и стек технологий
* **Среда выполнения:** Python 3.10+[cite: 14].
* **Предобработка:** `pymorphy3` (морфологический анализ, нормализация словоформ), модуль `re` (фильтрация небуквенных символов).
* **Векторизация:** `TfidfVectorizer(ngram_range=(1, 2), max_features=3000, sublinear_tf=True)`.
* **Классификация:** библиотека `scikit-learn` (`LinearSVC`, `CalibratedClassifierCV`).
* **Маршрутизация:** калибровка вероятностей методом Платта с установкой доверительного порога `Threshold = 0.60` (при падении уверенности ниже порога обращение маркируется флагом ручной верификации оператором).
* **Сериализация:** `joblib` (`model_pipeline.joblib`).
